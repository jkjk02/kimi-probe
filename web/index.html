如何判断一个 Kimi 接口是否“真”

  1. 分词计数一致性：usage.prompt_tokens 必须等于官方 tokenizer 的计数，偏差 > 2% 即可疑。
  2. 隐藏提示词：官方计数与 usage 的差值应恒为 0~2，且不随输入长度变化。
  3. 固定参数约束：官方平台对 temperature=0.2 / top_p / n=2 一律返回 400，中转清洗参数后就不会报错。
  4. 思考模式：K3 恒返回 reasoning_content 且拒绝 thinking 参数；K2.6 可关闭思考。
  5. 缓存命中：同前缀连续请求 cached_tokens 应接近 prompt_tokens，前缀变更后应归零。
  6. 联网 / 多模态 / 视频：用运行时生成的随机内容验证，模型无法靠记忆作弊。

填写左侧配置后点击「开始检测」。每次完整运行约消耗 3 万～8 万 tokens（视模型与推理强度而定）。
